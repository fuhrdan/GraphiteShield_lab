## [1.0.0] - 2026-08-21

### Added

- Eight-tab Java desktop defensive-research interface
- Seven synthetic mobile-threat experiment scenarios
- Adjustable experiment playback speed
- Live synthetic telemetry generation
- Telemetry search, severity filtering, sorting, and inspection
- Configurable detection rules with manual rule testing
- Finding acknowledgement, closure, and reopening
- Session risk scoring and dashboard
- Multiple synthetic Android-style device profiles
- CSV telemetry export
- Styled standalone HTML investigation reports
- Sample dataset generation
- Windows launcher
- macOS/Linux launcher
- Packaged runnable JAR
- Explicit local-only safety boundary

### Safety

- No exploits
- No real-device connection
- No ADB integration
- No command-and-control behavior
- No collection of real messages, credentials, location, audio, files, contacts, or other personal data
- Synthetic identities and telemetry only
- Documentation/test network fixtures only
